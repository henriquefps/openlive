# Screenshot assets

The pictures `pnpm screenshots` puts in the README gallery: each person's profile photo
(`avatar-<name>.jpg`, 512 x 512), their camera (`cam-<name>.jpg`, 1280 x 720) and the stills the
helpers stream (`stream-game.jpg`, `stream-movie.jpg`, `stream-desktop.jpg`, 2560 x 1440), for
Ana, Bruno, Carla, Diego, Eva and Felipe.

They are AI-generated (Gemini image generation) for this project: fictional people, no real person,
brand or copyrighted work. Use them freely, as CC0-style project assets.

A missing file is drawn as a neutral stand-in in the git-ignored `../.provisional/` and logged, so
the pipeline still runs (`src/assets.ts`).
